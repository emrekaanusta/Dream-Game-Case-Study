# Inside the Puzzle

**A Game Design Case Study & Interactive Analysis Website**

Inside the Puzzle is a game design case study exploring the mechanics, level progression, booster systems, obstacles, and player experience of popular mobile puzzle games.

The website brings together gameplay observations and design analysis to examine how different puzzle games introduce mechanics, build complexity, and keep players engaged.

## Games & Case Studies

- **Royal Match** — Analysis of core gameplay mechanics, power-ups, obstacles, and level progression.
- **Toon Blast** — Exploration of blast-based puzzle mechanics, boosters, obstacles, and progression.
- **Game Comparison** — A comparative analysis of gameplay systems and level design approaches.
- **Animal Haven** — An original match-puzzle game concept informed by the analysis of existing games.

## Project Goals

- Understand how successful mobile puzzle games introduce and develop gameplay mechanics.
- Analyze power-ups, boosters, obstacles, and level difficulty.
- Compare different approaches to puzzle game design.
- Apply these observations to the design of an original game concept.
